# Ember Depths

A playable, original 2D dungeon crawler built with vanilla HTML, CSS, JavaScript, and Canvas. No packages, build step, accounts, or external assets required.

## Play

Open `index.html` directly in a modern browser, or serve this folder with `python -m http.server 8000` and visit `http://localhost:8000`.

- Move: **WASD / arrow keys**
- Aim: **mouse** (keyboard and touch automatically target the nearest enemy)
- Attack: **hold Space / J / left mouse**
- Dash: **Shift**
- Open chests, use doors, shop, descend: **E**, while standing nearby
- Heal: **Q** (55 health per flask)
- Equipment: **I**
- Pause: **Esc / P**

Touch devices have a movement joystick and attack, dash, heal, and use buttons. Clear enemies to unlock room doors. The floor map shows your current room, the central merchant, and the guardian in the bottom-right room. Defeat all five guardians and use the last staircase to win.

## Features

Three starting classes; five themed floors with nine rooms each; randomized enemies, obstacles, chest contents, and merchant stock; four enemy types and charging guardians; twelve original weapons across four rarities; six relics; branching level-up blessings; healing flasks; dash invulnerability; optional synthesized sound; local autosave and continue. Classes can equip every weapon type.

Progress is stored in this browser’s local storage. It doesn’t sync between devices; private browsing or clearing site data may erase it. Starting a new run replaces the previous run. Death ends the run, while best depth remains.

## Publish on GitHub Pages

1. Create an empty GitHub repository, such as `ember-depths`.
2. Upload **the contents of this folder** to the root of its `main` branch: `index.html`, `style.css`, `game.js`, `README.md`, and `.nojekyll`.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/ (root)**, and Save.
4. GitHub displays the game’s published URL when deployment finishes.

Everything uses relative paths, so project Pages URLs work. No server backend or paid services are needed. The repository must have GitHub Pages available under your account plan.

## Customize

Edit `WEAPONS` near the top of `game.js` to change item names, rarity, damage, firing rate, range, color, and effects. Weapon IDs must stay unique. Supported effects: `frost`, `burn`, `pierce`, `triple`, and `leech`. Add relic behavior in `addRelic`, `damageValue`, `update`, `hurtPlayer`, or `checkClear` alongside the `RELICS` definitions. The `FLOORS` and `COLORS` lists define each floor’s name and palette.

Version: 0.1. Single player. Art and sound are generated by the game code.
